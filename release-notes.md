Voice features: system STT + system TTS.

- **System voice typing** (Settings > General > "Use system voice typing"): record with the phone's built-in speech recognition instead of the configured speech-to-text model. Works offline, no transcription model needed.
- **Phone voice** (Settings > General > "Use phone voice"): read replies aloud with the phone's built-in text-to-speech (the engine from the system speech settings) instead of the configured speech model. Works offline.

Both toggles take effect immediately and work in talk mode and auto-play.
